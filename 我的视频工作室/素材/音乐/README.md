## 注意：剪映可商用音乐的使用范围

剪映音乐库标"可商用"的曲子，授权通常是跟着"用剪映做的视频"走的。我们的视频是用代码做的，再把音乐导出来用，是否在授权范围内，我没法确认。

**最稳妥的做法**：成片交付时同时给一版"**无音乐版**"。你在剪映里导入无音乐版，从剪映音乐库加上同一首曲子，按 `节拍表.md` 里的剪辑点（原曲 0–37.93 秒 + 原曲 11.70 秒到结尾）拼好，再从剪映导出发布。这样授权链条最干净，节拍也对得上。
