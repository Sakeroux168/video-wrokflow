# 风格说明 · 《没事》

> 风格来源：[lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) → `styles/shadow-puppet`（皮影戏，MIT 许可）。
> 只借"语法"（材质、光、动作规矩），**不照搬它 demo 里的任何人物、故事（后羿射日）、旋律**。

---

## 1. 一句话风格

**一块被油灯从背后照亮的白布；布上是半透明的染色牛皮人偶，镂空的地方透出最亮的光。**

本片的核心比喻就建立在这个材质上：

> **一句话带来的"新东西" = 透过这块皮透出来的光。**
> 镂得越多（越猜不到）→ 透光越多；整块实心皮（一猜就中）→ 一点光都不透。

## 2. 颜色

所有颜色都是"灯光透过染色皮"出来的：**没有比灯更亮的东西，所有颜色都偏暖**。

### 染料（取自皮影 demo 的 `carve.js`）

| 用途 | 名称 | 色值 | 本片里给谁 |
|---|---|---|---|
| 主角 A（说「没事」的人） | 靛蓝 blue | `#2a5690` | 衣服主色——冷、收着 |
| 主角 A 袖子 | 青 teal | `#22647e` | |
| 主角 B（问"怎么了"的人） | 朱红 red | `#b8211a` | 衣服主色——暖、在靠近 |
| 主角 B 袖子 | 赭黄 gold | `#c98a26` | |
| 老两口（反转段） | 翠 jade `#2f8a5c` + 橙 orange `#d9541c` | | 和主角区分开 |
| 中性 | 原皮 hide | `#e2bd80` / `#cf9f5e` | 家具、道具、字牌底 |
| 墨 | ink | `#1a100a` | 轮廓线、头发、所有"必须看清的细东西" |
| 最亮 | 镂空透光 | （≈ 灯色 `#f4ead2`） | 只留给"新信息"的时刻 |

### 舞台

- 漆框：`#2a0d08` / `#46140c`，金线 `#8a6430`
- 印章红：`#b3261b`
- 字牌文字：米白 `#f3e2bf`

### 颜色规矩

1. 一个画面最多 3–5 种染料 + 原皮 + 墨
2. **亮度靠"点几盏灯"控制，不靠调色**。夜里 = 灯少，**不准加蓝色滤镜**
3. 皮重叠的地方会变暗——提前设计谁压着谁
4. 暗角一律偏**暖棕**，不准灰

## 3. 字体

| 用途 | 字体 | 许可 |
|---|---|---|
| 片名、关键字牌（「没事」「我不想说」「我爱你」） | 马善政 Ma Shan Zheng（毛笔体） | SIL OFL 1.1 |
| 字幕 / 说书人字牌 | **待确认**：建议 思源宋体 / Noto Serif SC | SIL OFL 1.1 |
| 西文（如需要） | Cormorant Garamond 600 | SIL OFL 1.1 |

字的规矩：

- **关键词是"刻出来的"**：深色皮牌，字用镂空刻掉，所以字本身在发光；牌子挂在竹签上，"按"上布进场、"提"离布退场
- **字幕是说书人的字牌**：窄长的暗漆木牌 + 细金线 + 小红印章（印章刻一个「说」字），米白字，轻轻滑入
- 字幕停留 ≥ max(1.8 秒, 台词时长 + 0.6 秒)
- 竖版 3:4 下，字幕字号 ≥ 44 px（1080 宽），每行 ≤ 14 个汉字

## 4. 动作规矩

| 规矩 | 具体 |
|---|---|
| 帧率 | 24 fps 连续；只有"火、水"这类替换件按 12 fps 跳 |
| 手抖 | 每个人偶都有轻微手抖（几像素、约 0.02 弧度、低频）；紧张时更抖 |
| 关节 | 身体跟主签滑动；腿、穗子、帽翅是**挂在铆钉上自己晃**的（阻尼摆） |
| 脸 | **脸永远不变**。情绪只靠 头的角度 + 身体倾斜（抬头=坚定，低头=难过） |
| 亮相 | 碎步 → 停 → **在一声锣/板上定格**约 1 秒（只有挂件在晃）→ 转头 |
| 进场/退场 | 进场：从灯那边来，大而虚，"啪"地贴上布变清楚（约 0.5 秒）；退场：变大、变虚、淡出（约 1 秒） |
| 换件 | 不变形，只"换一块皮"（比如「没事」牌换成「我不想说」牌） |
| 不动的东西 | 布、框，永远不动 |

## 5. 镜头

- 人偶一律**侧脸**；布上大部分空着
- 推近时不出黑边；推镜对准画面中心
- 转场只用：灯暗下去 / 前景柱子虚化划过 / 一块皮被提走露出光 / 闪一下暖白
- **不准用**：普通淡入淡出、数码划像、缩放转场

## 6. 声音（等音乐方案确认后细化）

- 先锣鼓、后弦乐：堂鼓、板鼓/木鱼、小锣（上扬"台"）、大锣（下沉"匡"）
- 安静的段落只留一件：一声醒木 / 一声灯芯"噗" / 一口气
- 留白要"硬切"，不让背景声漏进静场
- 配音（如有）：说书人口吻、短句；人声比音乐高 ≥ 12 dB；整体 −14 LUFS

## 7. 🚫 不准用的套路

**内容上**

- ❌ 开头讲公式、讲"信息论之父香农"
- ❌ 出现 熵 / 比特 / log / 概率 等名词
- ❌ 编数据（"研究表明 73% 的情侣……"）
- ❌ 画假的聊天界面、假的 App 截图、假的微信对话框
- ❌ 说教口吻："你必须……""千万不要……"
- ❌ 结尾硬塞"点赞关注"大字

**画面上**

- ❌ 纯黑剪影片（颜色是第二主角）
- ❌ 剪纸风、扁平矢量风、彩色玻璃风
- ❌ 粒子特效、发光描边、霓虹、渐变按钮
- ❌ 人物换表情、嘴型动画
- ❌ 普通淡入淡出、PPT 式飞入
- ❌ 夜景加蓝调；暗角发灰
- ❌ 浅色细线（会在亮布上消失）——细东西一律用深色

**声音上**

- ❌ 钢琴 + 弦乐的"感动煽情"罐头配乐
- ❌ 静场里有背景音乐漏进来
