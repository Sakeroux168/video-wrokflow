# 风格说明 · 《没事》

> 第二步：找参考。来源只有一个：你给的参考片《Vibe 知识大赏》（`素材/参考片/`，1920×1080，30 fps，149.5 秒）。
> 拆帧证据在 `检查记录/第02轮-找参考/`：每秒一帧的总览图 5 张，加 3 张逐帧拆动作的图。

## 0. 一句话风格

**扁平插画 + 大字报式标题**：暖色的家、深蓝的夜、米白的"讲道理纸面"。圆头小人演情景，粗黑体大字讲结论。
关键词一律**红字 + 黄色马克笔底**，一屏只说一件事。

## 1. 结构节奏（参考片怎么排 150 秒）

| 时间 | 段落 | 做法 |
|---|---|---|
| 0:00–0:16 | **情景钩子** | 没有标题，直接演：在外面对谁都客气，回到家对妈妈吼。观众 3 秒内认出"这是我" |
| 0:16–0:23 | **抛问题** | 黑场 → "为什么"大字砸进来 → 问题完整出现 |
| 0:23–1:26 | **分点讲（原因①–④）** | 每点 12–16 秒；顶部一颗"原因 ①"胶囊标签 + 一句大标题 + 一个比喻画面 |
| 1:26–1:36 | 情绪高点 | 暗场，只留文字和点阵 |
| 1:36–2:13 | **方法①–③** | 结构同"原因"，标签换成橙色"方法 ①" |
| 2:13–2:20 | **回到开头的场景** | 同一张饭桌，这次结局是好的 → 首尾呼应 |
| 2:20–2:29 | 金句落版 | 紫色暗底，两行字，一颗心 |

**节奏量出来的规律：**

- 硬切只有 5 次。段落之间几乎全靠**动画转场**：圆形扩散、黑场、放射光、斜切
- 每个画面里**大约每 1–2 秒就多出一个新元素**：气泡、标签、数字、箭头。画面不会"静着讲"
- 每段都是**先给画面、再给结论**：比喻先演出来，大标题后出现
- 开头那个场景在结尾**原样再来一次**，结局变好 → 观众有"闭环"感

**我们这支照搬的结构**（120 秒，按比例压缩）：情景钩子 → 抛问题 → 分点讲 → 收回"没事" → 反转 → 回到开头场景 → 金句。具体分配第三步在分镜表里定。

## 3. 字体

**全片只用一个字体家族：思源黑体（Source Han Sans，SIL OFL 1.1，可免费商用）。**参考片用的也是这种粗黑体。

| 用途 | 字重 | 16:9 字号（1080 高） | 备注 |
|---|---|---|---|
| 超大标题（"为什么"这种） | Heavy | 150–180 px | 一屏只放 3–4 个字 |
| 段落大标题 | Heavy | 110–120 px | 一行 ≤ 10 字 |
| 场景里的顶部标题 | Bold | 56–64 px | 如"回到家""在外面" |
| 胶囊标签（原因 ①） | Bold | 40 px | |
| 对白气泡 | Bold | 26–30 px | 白底圆角气泡，带小尾巴 |
| 底部小字幕/注释 | Medium | 24–28 px | 深色半透明胶囊底 |

字的处理：

- 大字带一层很淡的投影（向下 4 px，20% 黑），**不描边、不发光**
- 关键词换色 + 黄底，**不放大、不换字体**
- 9:16 版字号 = 16:9 字号 × 1.0（竖版宽 1080，和横版高一样），但每行字数减半，自动折行

## 4. 构图

### 16:9（1920×1080）

- **标题**：水平居中，顶部 1/4 内（字中心 y≈12%–28%）
- **胶囊标签**：标题正上方，居中
- **角色**：站在下 1/3，脚踩地平线 y≈83%；脚下一个扁椭圆阴影
- **双人对话**：左右各占 1/4 处（x≈22% 和 x≈75%），中间留空放道具或桌子
- **底部注释**：y≈95%，居中小胶囊
- **左右对比页**：两张圆角卡片，各占约 40% 宽，卡片上方各有一个小标题

### 9:16（1080×1920）——单独排，不从横屏裁

- 标题区：顶部 y≈10%–25%，每行 ≤ 7 字，可折 2 行
- 舞台区：y≈30%–75%，角色放大到横版的约 1.3 倍
- 双人对话改成**上下错位**或**缩小间距**，桌子缩短
- 左右对比页改成**上下两张卡片**
- 字幕区：y≈80%–90%
- 底部 10% 留空，给小红书的 UI 遮挡

## 5. 角色画法

- **圆头小人**：头约占身高 1/3，没有脖子；身体是圆角长方形，手臂只在需要动作时出现
- 脸：豆豆眼或一字眼，嘴是一条线或半圆。**表情可以变**（参考片靠换眼睛嘴巴表达情绪）
- 脸颊有两团淡粉腮红（开心时才出现）
- 不描边，纯色块 + 一层轻微的明暗
- 我们**自己设计角色**：同样的画法，但换发型和衣服配色，不照搬参考片里那两个人

## 6. 动作手感（逐帧量的，30 fps）

| 动作 | 参考片实测 | 用法 |
|---|---|---|
| **爆炸气泡/对白弹出** | 3 帧（0.1 秒）从 0 放大到约 115%，再 3 帧回到 100%；同时全屏闪一层红色、轻微晃动，约 0.3 秒退掉 | 情绪爆点 |
| **大标题砸入** | 先 6 帧压黑 → 字从约 2.5 倍、半透明，6 帧缩到 1 倍落定 → 一圈白色冲击环往外扩，带细小粒子 | 抛问题 |
| **圆形转场** | 画面中心一个小圆点，约 12 帧加速扩满全屏（先慢后快） | 换段落 |
| **标题逐字出现** | 每个字约 2 帧，淡入 + 轻微上移；整句出完后**停很久**（4–8 秒） | 所有标题 |
| **标签掉落** | 带一点旋转掉下来，落地回弹一次 | 列举 |
| **数字/进度条** | 数字连续滚动，进度条平滑变化 | 量变化 |
| **角色走路** | 上下颠，幅度小 | 移动 |

**对齐你在第五步定的规矩：**

- **小东西动作干脆**：气泡、标签、图标都在 3–6 帧（0.1–0.2 秒）内到位，带一次回弹
- **大东西落得沉稳**：角色、桌子、整块卡片用 12–18 帧（0.4–0.6 秒）缓入，不回弹或只回弹很小
- **文字进场快、停得久**：逐字 2 帧一字，整句出完后至少停 2.5 秒

## 7. 声音（初步，第四步细化）

- **参考片没有人声配音**（你确认过）：全片靠 字 + 配乐 + 音效
- 配乐全程垫底：整片响度很平（每 5 秒的平均音量都在 −15 到 −10 dB 之间），没有一处真正的静音
- 速度我量出来大约 113 或 146 BPM，两个结果打架，不准，所以不照它来。第四步用我们自己合成的音乐重新量
- 音效跟着画面元素走：弹出有"啵"，爆炸气泡有"砰"，转场有"嗖"

## 8. 参考片的招牌手法：怎么学

> 第一版这里我写得太死，把下面几样都划成了"不学"。你看完说这些不错，**改成：学，但按立项单里的红线边界学**。

| 参考片里的做法 | 学不学 | 我们这支怎么用 |
|---|---|---|
| **"耐心电量 4%"这种贯穿全片的仪表** | ✅ 学 | 这是比喻，不是数据。我们也做一个贯穿全片的仪表，比如"这句话里的新东西"，具体第三步定 |
| **"老板的批评 −20%"这类掉落标签** | ✅ 学 | 同上，比喻性数字。比如"又一次「没事」 −30%" |
| **"只剩 210 天"这种按假设算出来的数** | ✅ 学 | 可以用，但前提条件要在画面上写明（"如果……"），算术要对 |
| **"心理学：自我损耗"小标签** | ✅ 学，加一个条件 | 标签上的概念必须真实存在、和说法对得上。本片能用的是"信息论：信息量"。"没事 = 我不想说"是观点，不贴"科学认证" |
| **1:24 画出来的手机聊天界面** | ✅ 学，加一个条件 | 做成同一画风的**卡通道具手机**、通用气泡。不仿冒微信或任何真实 App 的样子和 Logo。"没事"在聊天框里出现，代入感很强 |
| **那两个具体角色**（姜黄衣服的年轻人 + 灰发奶奶） | ✅ 学画法，不原样照搬（已确认） | 那是原作者的角色形象。原样搬过来，小红书可能判搬运、限流，原作者也可以投诉。我们用**同样的画法、同样的人物关系**，只换发型和衣服配色，一眼看去还是同一个味道 |
| 金句页的心形收尾 | 第三步再定 | 我们的结尾是反转，到时看合不合适 |

## 9. 参考片 2：只学剧情形式（2026-10-30 加）

《外星人思想实验》（`素材/参考片/参考片2-外星人思想实验.mp4`，1280×720，60 fps，302 秒）。**画风不学**（它是写实的 AI 视频），只学怎么讲：

- 一个"要是……会怎样？"的问题撑起整片
- 外星人当旁白，一级一级往下推，每一级都有**看得见的身体变化**
- 人不停插嘴：惊讶、兴奋、不服、追问，**一问一答**推进
- 中段一句"真正可怕的才刚开始"，再升一级
- 底部一直有字幕条
- 结尾回到现实："这只是个思想实验"
