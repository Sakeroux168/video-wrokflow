# 节拍表 · 《没事》

> 第四步：配音乐。**画面、切镜头、音效、音乐共用这一套时间点。**
> 机器可读版：`源码/时间轴/timeline.json`（分镜事件）· `检查记录/第04轮-配音乐/节拍点.json`（实测起音点）

## 基本参数

| 项目 | 数值 |
|---|---|
| 配乐 | `素材/音乐/没事_配乐.wav`（原创，代码合成，无任何采样/现成曲子），试听版 `没事_配乐_试听.mp3` |
| 生成代码 | `源码/音乐/作曲.py` |
| 速度 | **100 BPM**，4/4 拍 |
| 一拍 | **0.6 秒** = 18 帧（30 fps） |
| 一小节 | 2.4 秒 = 72 帧 |
| 全长 | 120 秒 = **200 拍 = 50 小节** |
| 实测 | 用代码重新分析成片配乐：测得 **100.0 BPM**；除 0:00–0:03.6 刷屏段（故意越来越密，落在 1/8～1/32 拍细分上）和终和弦的余音外，强起音全部落在拍点 ±25 ms 内，中位偏差 8.7 ms |
| 响度 | 配乐单独 −17.5 LUFS，峰值 −1 dBFS（最终混音时和音效一起统一到 −14 LUFS） |

## 对齐规矩

- **切镜头**：只切在拍点上（0.6 秒的整数倍）
- **段内事件**（气泡、卡片、标签、动作）：落在拍点或半拍（0.3 秒）上
- **音效**：跟着它对应的画面事件，同一个时间点
- **刷屏段 0:00–0:03.6**：消息越来越快，每条消息落在音乐的音符上：0–2 拍每半拍一条，2–4 拍每 1/4 拍一条，4–6 拍每 1/8 拍一条
- 对齐前后挪动都不超过 0.3 秒（唯一例外：S04 倒计时改成每两拍一跳，即每 1.2 秒）
