## 全片一根线

| 道具 | 学自参考片的 | 在本片里 |
|---|---|---|
| **「没事」信息量仪表**（左上角，电池样式） | "耐心电量" | 每说一次「没事」掉一截，最后 0% 闪红；结尾说真话时满格变绿 |
| **卡通道具手机** | 1:24 的手机 | S01 钩子、S05 阿远视角、S06 雨夜打字又删、S11 换一句真话。同画风，不仿任何真实 App |
| **答题卡** | 1:39 的倒计时 | S03 让观众自己猜 A/B/C + 3-2-1 倒计时；S08 再用一次 |
| **掉落标签** | "老板的批评 −20%" | "又一次「没事」 −35%" |
| **概念小标签** | "心理学：自我损耗" | **"信息论：信息量"**（全片唯一的术语，真实概念） |

结构（v2）：**钩子 → 情景 → 你来猜 → 一句话讲透 → TA 听到了什么 → 后果（雨夜） → 反问 → 反转 → 两种 0 → 方法 → 回到雨夜 → 金句**

> **v1 → v2 为什么改**：你看 v1 到 0:14 就走神了。问题出在这四处：
> 1. 0:14 故事突然停了，换成"为什么"大字，开始上课
> 2. 猜"太阳从哪边升起"，跟「没事」、跟小林阿远都没关系，是绕出去讲课本
> 3. 角色从 0:20 消失到 1:15，40 多秒只有卡片和试管
> 4. 没有"接下来会怎样"的悬念，观众没有理由往下看
>
> v2 的改法：**故事一直不停**，道理藏在故事里讲；**让观众自己猜**，亲身体验"被猜中的话没信息"；加一个**"真有事的那天"的后果**当悬念，结尾回到那一天解开。去掉"原因 ①②③"这种课本标签

## 分镜

> 每一段写五件事：**开始画面 / 过程 / 结束画面 / 屏幕上的字 / 为什么要有这一段**。另附 9:16 怎么排、主要音效。

### S01 · 0:00–0:05 · 钩子（5 秒）

- **底色**：夜·外面（深蓝 `#19274e`，暗角）
- **开始画面（第 0 帧就有东西）**：画面正中一部卡通手机，聊天框里已有一条对方的气泡："怎么了？"
- **过程**：
  - 0:00.3 我方绿色气泡"没事。"**3 帧弹出**，回弹一下（啵）
  - 0:01.2 "没事。"气泡**裂成两半往下掉**，后面露出一个红色气泡"我不想说"；全屏闪一层红、轻晃 0.3 秒（砰）
  - 0:01.8 顶部标题逐字出现，第 1 行："你说的是「没事」"
  - 0:02.5 第 2 行："TA 听到的是「**我不想说**」"（红字黄底）
- **结束画面**：手机 + 两行标题定住，停约 1.7 秒
- **屏幕上的字**：怎么了？ / 没事。 / 我不想说 / 你说的是「没事」 / TA 听到的是「我不想说」
- **为什么**：前 2 秒必须有钩子。第 1.2 秒就把全片最反直觉的结论**演**出来，手机聊天框是每个人都在用的画面，一眼代入
- **9:16**：手机放大到画面中部偏上（y≈35%–65%），标题移到手机上方，每行 ≤ 7 字，折成 4 行

### S02 · 0:05–0:14 · 情景：一遍又一遍（9 秒）

- **底色**：暖·家里（杏橙墙、木地板、吊灯、窗）
- **开始画面**：圆形转场打开 → 饭桌。小林坐着低头，阿远端着碗从右边走进来。左上角仪表亮起：「没事」信息量 **100%**（绿）
- **过程**：
  - **第 1 次**（0:05.3–0:07.3）：阿远"怎么了？" → 小林"没事。" → 仪表 100% → **70%**；阿远点点头，坐下
  - 0:07.3 窗外月亮 → 太阳 → 月亮（过了一天）
  - **第 2 次**（0:07.6–0:09.8）：同样的对话，阿远停了半拍才坐下；仪表 → **35%**；标签掉下来："又一次「没事」 −35%"
  - **第 3 次**（0:09.8–0:12）：阿远刚说"怎么……"，"没事。"已经抢着弹出来；仪表 → **5%**（变红）
  - 0:12–0:14：仪表 **0%**，红色闪两下。阿远犹豫了一下，还是第 4 次开口："……怎么了？" 小林张嘴的一瞬间——**画面定格**
- **结束画面**：定格在小林张嘴、阿远等着回答
- **屏幕上的字**：顶部计数逐次换："第 1 次" "第 2 次" "第 3 次" "第 4 次"；气泡：怎么了？ / 没事。 / 怎么…… / ……怎么了？；标签：又一次「没事」 −35%
- **为什么**：代入感最强的一段，"这不就是我家"。同时把贯穿全片的仪表立起来。结尾定格，把下一段的"你来猜"直接递给观众
- **9:16**：饭桌缩短，两人间距收窄；仪表放到左上、标题下方；计数放顶部
- **音效**：每次"没事"一声闷闷的"嘟"，一次比一次低；仪表掉格"滴"

### S03 · 0:14–0:24 · 你来猜（10 秒）

- **底色**：保持 S02 的饭桌，定格画面整体压暗 40%，像暂停键
- **开始画面**：小林张嘴的定格
- **过程**：
  - 0:14.2 屏幕正中弹出一张答题卡（白底圆角卡片，3 帧弹出）："**你猜，小林这次会说什么？**"
  - 0:15.2 三个选项一个接一个弹出（每个 4 帧）：
    - A「没事。」
    - B「我今天被老板骂哭了」
    - C「我们分手吧」
  - 0:16.5 大号倒计时 3 → 2 → 1（学参考片 1:39 的倒计时），每秒一跳（嘀、嘀、嘀）
  - 0:19.5 解除定格，小林说出口："**没事。**"——A 选项亮绿，盖章"**猜中了吧**"（叮）
  - 0:21 标题逐字："你猜中了。所以这句话，**什么都没告诉你**。"
- **结束画面**：A 亮着 + 盖章 + 标题，停约 1.8 秒
- **屏幕上的字**：你猜，小林这次会说什么？ / A「没事。」 / B「我今天被老板骂哭了」 / C「我们分手吧」 / 3 2 1 / 没事。 / 猜中了吧 / 你猜中了。所以这句话，什么都没告诉你。
- **为什么**：v1 在这里开始上课，观众走神。v2 改成**让观众亲手做一道题**：选项 C 有点好笑，倒计时制造等待感，几乎所有人都会选 A，然后被一句"你猜中了，所以它什么都没告诉你"点醒。知识点是观众**自己体验到**的，不是听来的
- **9:16**：答题卡占满中部，三个选项竖排；倒计时放在卡片上方
- **音效**：定格"咔"；选项"啵啵啵"；倒计时"嘀嘀嘀"；猜中"叮"

### S04 · 0:24–0:36 · 一句话讲透（12 秒）

- **底色**：答题卡放大、铺满成纸·讲道理（米白）
- **开始画面**：答题卡往前推，填满画面
- **过程**：
  - 0:24.5 左边：A「没事。」气泡，下面一根试管 "**新消息**"，几乎空（只有一丝）
  - 0:26 右边：B「我今天被老板骂哭了」气泡，**亮起来**，试管**一下涨满**（啵）。旁边阿远的小头像冒出一串："啊？！为什么？谁？要不要紧？"
  - 0:28.5 标题逐字："**越能被猜中的话，带的消息越少**"（"越能被猜中"蓝、"越少"红字黄底）
  - 0:30 标题下掉一个黄色小标签："**信息论：信息量**"
  - 0:31.5 底部注释："B 你猜不到，所以一说出来，TA 一下就知道了好多事"
- **结束画面**：一空一满两根试管 + 标题 + 标签，停约 3 秒
- **屏幕上的字**：没事。 / 新消息 / 我今天被老板骂哭了 / 啊？！为什么？谁？要不要紧？ / 越能被猜中的话，带的消息越少 / 信息论：信息量 / B 你猜不到，所以一说出来，TA 一下就知道了好多事
- **为什么**：给刚才的体验起名字。用的还是**刚才那道题的两个选项**，不绕出去举别的例子。阿远那一串追问让"信息多 = 对方一下有很多可以接的话"变得看得见
- **9:16**：两组气泡 + 试管上下排
- **音效**：B 亮起"啵"；阿远追问一串快速"哒哒哒"

### S05 · 0:36–0:50 · TA 听到的是什么（14 秒）

- **底色**：夜·外面（深蓝），呼应 S01
- **开始画面**：圆形转场 → 和 S01 同一部卡通手机，这次是阿远的视角（手机下面露出阿远的半个头）
- **过程**：
  - 0:37 小林发来："没事。"
  - 0:38.5 "没事。"两个字像被橡皮擦一点点擦淡，气泡变成**空的透明气泡**（嘶——）
  - 0:40.5 空气泡后面浮出："**我不想说**"（红字黄底）（咚）
  - 0:42 标题逐字："内容 TA 早就猜到了，"
  - 0:43.5 第 2 行："TA 能读到的，只剩一件事：**你又不说**"
  - 0:46 阿远放下手机，回了一个字："哦。"
- **结束画面**：手机里"我不想说" + 阿远回的"哦。"
- **屏幕上的字**：没事。 / 我不想说 / 内容 TA 早就猜到了， / TA 能读到的，只剩一件事：你又不说 / 哦。
- **为什么**：核心结论落地，并且**站到被挡回去的那个人那一边**。观众大多两边都当过，这一下会疼
- **9:16**：手机居中放大，标题在手机上方
- **音效**：擦除"嘶"；"我不想说"一声低"咚"；"哦。"发出去的"嗖"

### S06 · 0:50–1:08 · 后果：真有事的那天（18 秒）

- **底色**：夜·外面，下雨（斜线雨丝，参考片 1:12 雷雨云同款画法）
- **开始画面**：顶部标题逐字："**后来有一天，小林真的有事了**"
- **过程**：
  - 0:52 小林一个人坐在路边台阶上，雨淋着，头低着，身边一个被风吹翻的伞
  - 0:54 小林拿起手机，屏幕特写：阿远的消息"今天怎么样？"
  - 0:55.5 小林开始打字，一行一行冒出来："今天项目搞砸了，被当着全组的面……"——停住——**一个字一个字删掉**（删除键"嗒嗒嗒"，越删越快）
  - 0:59.5 输入框里只剩光标闪了两下。小林打出："**没事。**"——发送（嗖）
  - 1:01 切到阿远：在家，看了一眼手机，"哦"了一下，把手机扣在桌上，继续看电视
  - 1:03 切回小林：手机屏幕慢慢**暗下去**，雨还在下
  - 1:04.5 标题逐字："**最需要 TA 问的那天，TA 已经不问了**"
- **结束画面**：暗掉的手机 + 雨里的小林 + 标题，停约 3 秒
- **屏幕上的字**：后来有一天，小林真的有事了 / 今天怎么样？ / 今天项目搞砸了，被当着全组的面…… / 没事。 / 最需要 TA 问的那天，TA 已经不问了
- **为什么**：v1 缺的就是**后果和悬念**。前面说了一百次"没事"都没什么，直到真有事的这天，代价才出现。"打了一长段又删掉"是几乎每个人都做过的动作，代入感最强。这一段也给结尾留了一个要解开的结
- **9:16**：小林和台阶放大居中；手机特写占满画面
- **音效**：雨声垫底；删除键"嗒嗒嗒"；音乐在 1:03 收到只剩一个长音
