## v3 的核心改动：旁白带着阿远走，观众就是阿远

> **v2 → v3 为什么改**：v2 把答题卡直接"扔给观众"，屏幕突然对观众说话，像出题考试。
> 你要的是：**画面里有两个人**——**旁白**带着**阿远**一路看、一路问；阿远替观众答题、替观众吃惊、替观众难过。
> **观众就是阿远**。旁白不跟观众说话，只跟阿远说话。

| 谁 | 作用 |
|---|---|
| **旁白**（新角色） | 带路的人。手里拿一个**遥控器**，能让画面**暂停、倒带、换台**。站在故事外面，只对阿远说话，叫他"阿远"、说"你" |
| **阿远** | 观众的替身。问"怎么了"的那个人。被旁白带着回看自己经历过的事，答题、吃惊、后悔、最后自己按下遥控器 |
| **小林** | 故事里说「没事」的人。阿远和旁白看着 TA，但 TA 看不见他们 |
| 爷爷、奶奶 | 反转段 |

**旁白怎么"说话"**：不配音，旁白的话用**紫色气泡**显示，气泡左上角挂一个小名牌"旁白"。每个气泡 ≤ 16 个字，长句拆成两个气泡接着弹。

## 分镜

> 每段写：**开始画面 / 过程（谁说什么）/ 结束画面 / 为什么要有这一段**，另附 9:16 排法和音效。
> 对白写法：**旁白：**"……" 表示紫色气泡；**阿远：**"……" 表示阿远的白色气泡。

### S01 · 0:00–0:05 · 钩子（5 秒）

- **底色**：夜·外面（深蓝）
- **开始画面（第 0 帧就有东西）**：阿远的手机特写（画面下方露出阿远半个头），聊天框里阿远刚发出："怎么了？"
- **过程**：
  - 0:00.3 小林回："**没事。**"（3 帧弹出，啵）
  - 0:01.2 "没事。"气泡**裂成两半掉下去**，后面露出红色气泡"**我不想说**"；全屏闪红、轻晃（砰）
  - 0:02 旁白从画面右边**探头进来**（3 帧，带回弹），举着遥控器
  - 0:02.3 **旁白：**"阿远，TA 说的是「没事」，"
  - 0:03.3 **旁白：**"你听到的是「我不想说」，对吧？"
  - 0:04 阿远转头看旁白，头上冒"？！"
- **结束画面**：裂开的气泡 + "我不想说" + 旁白 + 一脸懵的阿远
- **为什么**：钩子不变（第 1.2 秒就把结论演出来），同时**两个主角一起登场**：一个带路的、一个被带的。观众从第 2 秒就知道自己是阿远
- **9:16**：手机放大居中偏上，旁白从右下探头，气泡在手机下方
- **音效**：啵 / 砰 / 旁白探头"嗖"

### S02 · 0:05–0:15 · 倒回去看看（10 秒）

- **开始画面**：**旁白：**"我们倒回去看看。"——按遥控器"倒带"，画面带扫描线快速倒放（嗖嗖嗖）
- **过程**：
  - 0:06 倒带停在饭桌：小林低头坐着，阿远端着碗走来。旁白和阿远（带白边，回放模式）站在画面左边看。左上角仪表：「没事」信息量 **100%**
  - **第 1 次**（0:06.5–0:08.5）：过去的阿远"怎么了？"→ 小林"没事。"→ 仪表 → **70%**。**旁白：**"第 1 次，你信了。"
  - 0:08.5 窗外月亮 → 太阳 → 月亮（过了一天）
  - **第 2 次**（0:08.8–0:11）：同样的对话 → 仪表 → **35%**，标签掉下来"又一次「没事」 −35%"。**旁白：**"第 2 次，你犹豫了。"
  - **第 3 次**（0:11–0:13）：过去的阿远刚说"怎么……"，"没事。"已经抢着弹出来 → 仪表 → **5%**（变红）。**旁白：**"第 3 次，你还没问完。"
  - 0:13–0:15：仪表 **0%** 闪红。过去的阿远第 4 次张嘴："……怎么了？"——旁白按遥控器"**暂停**"，画面定格、压暗（咔）
- **结束画面**：定格的饭桌 + 旁白举着遥控器 + 回放模式的阿远
- **为什么**：代入（"这不就是我家"），同时让观众习惯"旁白 + 遥控器"的玩法。旁白一句一句点评，阿远（=观众）被说中
- **9:16**：饭桌缩短；旁白和阿远站在画面下方；仪表左上
- **音效**：倒带"嗖嗖"；每次"没事"一声闷"嘟"，一次比一次低；暂停"咔"

### S03 · 0:15–0:25 · 旁白：这三张卡，你猜一个（10 秒）
