## 1. 一句话 🔒

**看完要记住：**

> 「没事」说多了，对方听到的不是"没事"，而是"我不想说"。

| 层次 | 内容 |
|---|---|
| 核心结论 🔒 | 「没事」说多了 = 对方听到"我不想说" |
| 支撑知识点 🔒 | 一句话越容易被猜到，它带的信息就越少 |
| 结尾反转 🔒 | 信息量为 0 不等于没有意义。有些话（比如「我爱你」）重复也值得说，但「没事」不属于这种 |

**讲法的边界**（来自你的"不想要"）：
- 不一上来讲公式；全片不出现公式
- 不堆名词。只允许出现一个词：「信息量」，而且要先用例子演明白，再说出这个名字
- 不出现：香农、熵、比特、log、概率

### 为什么建议要配音

1. **这支片子讲的就是一句话"听起来"是什么意思。**"没事"两个字，平平地说、叹着气说、抢着说，意思完全不一样，只靠字幕演不出来。钩子那一下最需要声音
2. 120 秒的讲道理内容，没有人声带着走，观众很难看完
3. **同时全程烧录字幕**：小红书很多人静音刷，静音也要看得懂

配音分两种声音：
- **解说**：一个温和、偏口语的声音，像朋友在讲
- **角色对白**：两个角色各一个声音（"怎么了？""没事。"），第三步写分镜时一起定

### 卡住的事：阿里云连不上

- 这台云端机器的网络规则挡住了阿里云的语音合成服务器（`dashscope.aliyuncs.com`，返回 403）。需要你在**环境设置 → Network access** 里放行这个域名。操作说明见 https://code.claude.com/docs/en/cloud-environments#network-access
- **API 密钥请不要直接贴到聊天里。**请在**环境设置**里加一个环境变量 `DASHSCOPE_API_KEY`（有 "Network secrets / API credentials" 一栏的话就放那里），**新开的会话**才能读到
- 这两件事做好之前，我先往下做不依赖配音的部分（风格、分镜、音乐、画面）。**配音不会用假的顶替**
